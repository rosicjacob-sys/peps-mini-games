# Self-hosted display font

Drop `coffee-tin.woff2` (and/or `coffee-tin.ttf`) here — e.g. the "Coffee Tin" font by Rick Mueller — and rebuild the widget.
It is served next to `widget.js`, and the widget's font stack (`"Coffee Tin", "Rye", Impact`) picks it up automatically.
Until then the widget uses "Rye" from Google Fonts. Check the font's licence allows web embedding before adding it.
